# Contributing

Bug reports, ideas and measurements of real cases that do not fit are welcome in the [issues](https://github.com/R0adRunn3r/coverfold/issues). For a printing problem, say which template, which measurements, the paper and the printer settings.

## Development

```bash
npm install
```

```bash
npm run dev
```

Before opening a pull request, run the tests and the linter:

```bash
npm test
```

```bash
npm run lint
```

- React belongs in `src/ui` only: `src/core` and `src/engine` stay framework-free (an ESLint rule checks it).
- Every visible string goes in both `src/i18n/en.json` and `src/i18n/it.json`.
- Comments explain what the code cannot say by itself, briefly. No decorative separators.
- Template geometry is generated by code from measurements: add a test in `src/core` when you change it.
